# ATP – IIT Student Intranet

## Project Overview

This project is my individual contribution to the Advanced Technologies and Practices (ATP) group coursework. It focuses on developing the Student Intranet interface for the Informatics Institute of Technology (IIT).

The Student Intranet provides students with a simple and user-friendly interface to access important academic information, student services, campus resources, and support information.

## Features

The Student Intranet consists of seven main sections:

1. **Overview** – Student dashboard with an overview of important information.
2. **Schedules** – Access to student schedules.
3. **Academics** – Academic-related information and resources.
4. **Student Services** – Information about student services.
5. **Policies and Forms** – Access to policies and relevant forms.
6. **Campus Life** – Information about campus activities and student life.
7. **Help and Support** – Student assistance and support information.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

The project contains separate HTML pages for each Student Intranet section, along with shared CSS stylesheets, JavaScript files, and image assets.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Locate `iit_intranet_portal.html`.
4. Open the file in a web browser to access the login page.
5. Use the available navigation options to explore the Student Intranet.

## Login Information

The login functionality is implemented as a demonstration interface. It does not use a real authentication system or connect to a production database.
