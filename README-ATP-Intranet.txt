ATP IIT Student Intranet - Multi-page Student Portal

PROJECT CONTENTS
- iit_intranet_portal.html : Existing login page (preserved)
- student-dashboard.html   : Student Overview page
- schedules.html           : Schedules & calendars page
- academics.html           : Academic resources page
- student-services.html    : Student services page
- policies-forms.html      : Policies & forms page
- campus-life.html         : Campus life page
- help-support.html        : Help & support page
- student-dashboard.css    : Shared IIT dashboard styling
- student-dashboard.js     : Overview page interactions
- student-pages.css        : Shared styling for the six resource pages
- student-pages.js         : Resource page interactions
- IIT logo image files     : Existing IIT branding assets

HOW TO RUN
1. Extract this ZIP file.
2. Open the IIT_Intranet folder in VS Code.
3. Open iit_intranet_portal.html with Live Server.
4. Use the demo Google sign-in or student email sign-in.
5. After successful demo sign-in, the browser opens student-dashboard.html.
6. Use the left Student Intranet menu to open each separate page.
7. Use Sign out to return to the login page.

NAVIGATION
The left sidebar links to seven separate HTML pages:
Overview, Schedules, Academics, Student services, Policies & forms,
Campus life, and Help & support.

RESOURCE PAGE BEHAVIOUR
- Resource rows/cards are clickable UI controls but do not open another page.
- The global search and page search filter the resource categories on the current page.
- Notification buttons show a small demo message.
- Only the sidebar navigates between the seven student pages.
- Sign out returns to the login page.

IMPORTANT
This is a front-end prototype. The login flow is simulated for demonstration
and does not authenticate or validate real IIT student credentials.
